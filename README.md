
## 🚀 Main Application File

The heart of this project is **`src/App.jsx`**, which serves as the **root component** of the website. It brings together the application's layout, content, and reusable components to create the complete user experience.

### ✨ Responsibilities of `App.jsx`

* 🏠 Renders the main website layout.
* 📑 Displays all major sections of the application.
* 🧩 Imports and organizes reusable React components.
* 🎨 Controls the overall structure and presentation of the user interface.
* ⚡ Acts as the central component where the application is assembled.
